# Recipin 📌

**ספר המתכונים שלך.** מקום אחד לכל המתכונים, עם תצוגה בסגנון פינטרסט, תיוג חכם ושיתוף בקישור.
השם הוא שילוב של Recipe (מתכון) ו-Pin.

## מה יש בגרסה הזו (MVP)

**שלוש דרכים לתייק מתכון**
- **🔗 מקישור:** מדביקים קישור ו-Recipin מפרק את המתכון למצרכים, שלבים, זמנים, כמות ותמונה, **בלי AI**.
  הוא קורא את נתוני Schema.org/Recipe שרוב אתרי המתכונים מפרסמים בשביל גוגל
  (JSON-LD, ואם אין אז Microdata). כשאין נתונים מובנים, המתכון נשמר ככרטיס קישור (כותרת ותמונה), ואפשר להשלים אותו ידנית.
  התמונה מורדת ונשמרת מקומית, כך שהמתכון נשאר גם אם האתר משתנה או נעלם.
- **📷 מתמונה:** מצלמים דף מספר, כתב יד או צילום מסך. אפשר להעלות כמה תמונות.
- **✍️ כתיבה חופשית:** עם תמונות. שורה שמתחילה ב-`##` הופכת לכותרת משנה (למשל `## לבצק`).

**התמצאות**
- גריד בסגנון פינטרסט, חיפוש בשם, במצרכים, בתגיות ובהערות, וסינון לפי כמה תגיות יחד.
- **תגיות אוטומטיות** לפי המצרכים והזמן: בשרי, חלבי, פרווה, טבעוני, צמחוני, דגים, "עד 30 דקות" ו"הכנה ארוכה".
  המערכת מכירה חריגים כמו חלב קוקוס, חמאת בוטנים ושמנת צמחית. כל תגית אוטומטית מסומנת בירוק וניתנת להסרה.
  אין בכוונה תגית אוטומטית "ללא גלוטן", כי טעות בה עלולה להזיק לחולי צליאק.
- תגיות שהאתר המקורי מציע (קטגוריה, מטבח, מילות מפתח) מתווספות אוטומטית.
- אוספים (למשל "שבת" או "מתכוני סבתא"), מועדפים, הערות אישיות והתראה על מתכון שכבר שמור.

**שיתוף**
- קישור צפייה לכל הספר, לאוסף או למתכון בודד, עם כפתורים לוואטסאפ, למייל ולשיתוף מהטלפון.
- ההערות האישיות לא משותפות. אפשר לבטל קישור בכל רגע (בעמוד "שיתופים").

**תיוק מהיר**
- **Bookmarklet:** כפתור לסרגל הסימניות שמתייק את הדף הפתוח בלחיצה אחת.
- **אנדרואיד:** מתקינים את Recipin למסך הבית (PWA), והוא מופיע בתפריט "שיתוף" של כל אפליקציה.

## הרצה

נדרש Node.js בגרסה 22.13 ומעלה (משתמשים ב-SQLite המובנה ב-Node, בלי התקנת מסד נתונים).

```bash
npm install
npm start            # http://localhost:3000
npm test             # בדיקות
```

הגדרות (משתני סביבה):

| משתנה | תפקיד |
|---|---|
| `PORT` | פורט (ברירת מחדל 3000) |
| `RECIPIN_DATA` | תיקיית הנתונים: מסד הנתונים והתמונות (ברירת מחדל `./data`) |
| `RECIPIN_PASSWORD` | סיסמה לעריכה. **חובה כשמעלים לשרת ציבורי.** קישורי השיתוף נשארים פתוחים. |

הגיבוי פשוט: מעתיקים את תיקיית `data`.

## מבנה

```
server/
  extract.js   פירוק מתכון מדף אינטרנט (JSON-LD → Microdata → Open Graph)
  autotag.js   תגיות אוטומטיות לפי חוקים
  db.js        SQLite: מתכונים, תגיות, אוספים, שיתופים
  net.js       הורדה בטוחה (חוסם כתובות פנימיות)
  app.js       API + הגשת האפליקציה
public/        האפליקציה (JS נקי, בלי שלב build), RTL, מותאמת לנייד ולמצב כהה
test/          בדיקות לפירוק, לתיוג ול-API
```

## השלבים הבאים
- מצב בישול: מסך שלא נכבה, טקסט גדול וטיימרים מתוך ההוראות.
- שינוי כמויות לפי מספר מנות, והמרת יחידות (כוסות↔גרם, פרנהייט↔צלזיוס).
- רשימת קניות מאוחדת ותכנון ארוחות שבועי.
- OCR לתמונות (ML Kit או Tesseract) כדי להפוך צילום לטקסט.
- משתמשים וחשבונות: ספר משפחתי משותף עם הרשאות עריכה.
- ייבוא מאינסטגרם וטיקטוק, וייצוא ל-PDF או ספר מודפס.
